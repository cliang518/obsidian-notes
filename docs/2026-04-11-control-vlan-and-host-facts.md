# 2026-04-11 控制平台与 VLAN 事实记录

## 来自现场的新事实

1. 风控系统在接入视角上属于“同主机多目录”形态：
- 同一台电脑/主机承担风控相关服务。
- 通过不同目录路径区分新项目与老项目。
- 访问侧可能表现为双 IP 或多入口，但业务上需要支持同一实例下多个入口。

2. 电控系统属于独立主机实例：
- 电控平台不是与监控 VLAN 同域。
- 电控与风控线路同在弱电井交换机体系中，但 VLAN 与监控域隔离。

3. 监控网络已知事实：
- 监控网明确存在 VLAN2。
- 弱电井交换机还有其他 VLAN 端口，推测承载风控/电控等业务域。

## 在 V2 中的建模要求（已执行）

1. 控制平台登记支持“实例 + 入口”分层：
- `instance_name` / `instance_code`
- `endpoint_name` / `endpoint_path`

2. 控制平台登记支持网络分域字段：
- `vlan_id`
- `vlan_name`
- `network_zone`

3. 拓扑中心增加 VLAN 统计视角：
- VLAN 端口分布
- 网络分域概况（监控域 vs 风控/电控或其他域）

## 后续待核验项

1. 风控新/老入口实际是否稳定映射到同一主机（或同一实例群组）。
2. 风控/电控 VLAN 具体编号、命名、上联口与级联关系。
3. 交换机端口 -> VLAN -> 设备归属 -> 楼层区域链路的完整闭环。
