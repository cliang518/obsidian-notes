# 永嘉集团信息弱电视频运维系统 V2 使用说明

> 适用于开发主机、部署主机和后续正式服务器。  
> 当前版本：`1.1.0`

## 1. 系统定位

这套系统用于商场弱电视频运维的日常工作闭环，核心目标是把下面几类工作统一到一个平台里：

- 设备台账
- 在线检测
- RTSP 预览
- 快照抓拍
- 告警中心
- 工单处理
- 巡检与维保
- 资料与知识库
- 控制平台接入
- 存储、模型、智能体预留接口

系统不是单纯的“摄像头列表”，而是一个可以持续积累数据、逐渐替代第三方平台的运维底座。

## 2. 首次登录

### 2.1 访问地址

- 本机访问：`http://127.0.0.1:3011`
- 局域网访问：使用开发主机或部署主机的实际 IP 加端口
- 后端健康检查：`http://127.0.0.1:8011/api/system/health`

### 2.2 登录方式

首次使用时，系统会自动带出一组默认管理员账号用于初始化测试。现场正式使用时建议尽快修改密码并启用分级账号。

## 3. 首页总览

首页用于快速看“系统现在是否健康”。

### 页面能看到什么

- 当前设备、摄像头、交换机、平台节点的概览
- 告警总数、待处理数、恢复数
- 工单数量
- 巡检任务
- 存储、模型、智能体接口状态
- 控制平台、视频平台接入概况

### 典型用法

1. 登录后先看首页。
2. 检查右上角的运行状态是否正常。
3. 如果首页显示告警较多，先进入告警中心查看是否为网络抖动类问题。

## 4. 设备管理

设备管理是系统的基础台账页。

### 主要用途

- 查看摄像头、交换机、NVR、解码器、网关、平台节点
- 查看设备 IP、厂商、型号、区域、来源
- 进行添加、修改、删除
- 做批量导入、批量替换、批量合并

### 常见操作

#### 新增设备

1. 进入设备管理。
2. 点击“新建”。
3. 填写 IP、名称、类型、区域、备注等信息。
4. 保存。

#### 批量导入

1. 准备 Excel 或 CSV 数据。
2. 进入导入功能。
3. 选择导入策略：
   - 只新增
   - 先替换后合并
   - 按 IP 匹配更新
   - 条件插入部分字段
4. 预览结果。
5. 执行导入。

#### 典型导入逻辑

- 如果表格里已有 `ip` 字段，就按 `ip` 匹配系统中的摄像头或设备。
- 如果只提供了尾号，则需要结合区域、楼层、端口、来源平台进一步匹配。
- 如果同一台设备在多个平台出现，以“来源优先级 + 可信度 + 最近导入结果”为准。

## 5. 在线检测

在线检测是系统最重要的功能之一。

### 逻辑说明

- 不只做简单 `ping`
- 需要结合：
  - 管理 IP 可达性
  - RTSP 取流可用性
  - 账号密码是否正确
  - 交换机端口、ARP、VLAN、来源平台事实
  - 最近一段时间的抖动行为

### 结果含义

- `在线`：可达、认证正常、取流正常
- `可达异常`：IP 不通或链路不可达
- `离线`：长时间不可达且无恢复迹象
- `网络抖动观察`：短时间反复上线下线，不直接算固定离线

### 使用建议

1. 先看“在线概览”。
2. 再看“异常设备列表”。
3. 对反复抖动的设备优先关注其所在交换机、VLAN、端口和楼层归属。

## 6. 告警中心

告警中心用于看异常、处理异常、导出异常和清理历史数据。

### 页面区块

- 概览卡片
- 防风暴参数
- 告警列表
- 批量操作
- 导出
- 历史清理

### 处理流程

1. 先看概览卡片，判断是不是大面积异常。
2. 如果是单点异常，直接点开设备查看详情。
3. 如果是抖动类告警，先看是否被系统归入“网络抖动观察”。
4. 如果确认是误报，可以批量确认、批量恢复或批量删除。
5. 历史记录需要定期清理和导出，避免页面积压。

### 风暴防护

当系统判断为大面积异常时，通知不会无脑狂发。

- 普通通道默认抑制逐条通知
- 管理员可以在通知中心选择强制下发

## 7. 视频中心

视频中心主要负责：

- RTSP 预览
- 快照抓拍
- 视频平台接入
- 摄像头和通道映射查看

### 使用步骤

1. 进入视频中心。
2. 选择设备或通道。
3. 点“预览”查看实时画面。
4. 点“快照”抓取当前画面。
5. 如果画面打不开，先核对：
   - IP 是否正确
   - 账号密码是否正确
   - RTSP 地址是否正确
   - 平台节点是否在线

## 8. 控制平台

控制平台页用于接入风控、电控等平台事实来源。

### 适用场景

- 读取第三方平台中的设备、菜单、点位、场景信息
- 导出注册轨道
- 清空审计数据重新导入
- 比较新旧平台差异

### 使用原则

- 第三方平台默认只读
- 先导入事实，再做替代
- 风控、电控平台暂时保留接口，后续可逐步替代

## 9. 工单中心

工单中心用于把告警、巡检、现场问题统一成处理闭环。

### 常见工单类型

- 告警跟进
- 平台审核
- 现场维修
- 巡检复核

### 典型流程

1. 告警出现后创建工单。
2. 分配给维修人员。
3. 现场处理后回填说明、照片和结果。
4. 完成后关闭工单。

## 10. 巡检与维保

巡检用于定期检查设备、链路和告警趋势。

### 建议做法

- 每日看告警中心
- 每周出巡检报告
- 每月出月报
- 对网络抖动设备做持续观察

## 11. 托盘程序

托盘程序是这套系统“像服务器一样常驻运行”的关键入口。

### 能做什么

- 双击启动主系统
- 右下角托盘常驻
- 右键菜单管理服务
- 开机自启
- 查看状态
- 停止服务

### 使用建议

1. 正式部署后，建议以托盘方式运行。
2. 如果前端或后端异常，先看托盘日志。
3. 如果托盘出现重复窗口，先确认是不是旧进程未退出。

## 12. 备份与恢复

### 备份

- 进入运行中心或直接调用系统备份接口
- 备份会保留：
  - 数据库
  - 配置
  - 运行期重要文件
  - 轨迹/导入结果

### 恢复

恢复时建议按以下顺序：

1. 停止系统
2. 恢复数据库和运行目录
3. 检查端口
4. 启动后做冒烟测试
