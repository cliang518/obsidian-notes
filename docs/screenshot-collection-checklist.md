# 永嘉集团信息弱电视频运维系统 V2 截图采集清单

> 用于给《系统使用说明》补图。  
> 建议按下面顺序逐张采集，后续直接按文件名放进 `docs/screenshots/`。

## 1. 采集前准备

1. 打开系统并登录。
2. 清理浏览器里不必要的弹窗。
3. 保持窗口宽度尽量接近现场常用分辨率。
4. 截图尽量包含完整页面标题和关键按钮。
5. 如果页面有分页，保留页脚。
